## 使用建议

### 对于 AI 助手

1. **自动应用的规则** (00, 01, 03) 会在编辑对应类型文件时自动加载
2. **手动触发的规则** (02, 04, 05, 06, 07) 在用户询问相关问题时引用
3. 规则之间可以相互引用,使用 `[文件名](mdc:文件路径)` 格式
4. 优先遵循项目规范,保持代码风格一致性

### 对于开发者

你可以通过以下方式让 AI 应用特定规则:

```
# 开发新接口
"我要开发一个获取股票数据的新接口,请帮我"

# 查看代码模式
"如何使用 pandas 处理分页数据?"

# 调试问题
"我的接口返回乱码,如何调试?"

# 提交代码
"我准备提交代码,需要做什么?"
```

## 规则维护

### 更新规则

当项目规范发生变化时,更新对应的规则文件:

1. 编辑 `.cursor/rules/*.mdc` 文件
2. 确保 frontmatter 元数据正确
3. 更新本 README 说明
4. 提交更改到版本控制

### 添加新规则

创建新规则文件时:

1. 使用 `.mdc` 扩展名
2. 添加 frontmatter 元数据:
   ```yaml
   ---
   alwaysApply: true  # 或 false
   description: "规则描述"  # 用于手动触发
   globs: "*.py"  # 文件匹配模式(可选)
   ---
   ```
3. 使用 Markdown 格式编写内容
4. 在本 README 中添加说明
5. 使用数字前缀保持顺序
